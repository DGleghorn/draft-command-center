🔴 Live draft mode

Turn this on during your actual live draft to log every real pick — yours and your opponents' — instead of relying on simulated bot picks.

When ON, every "Draft" button becomes "Log Pick" and works regardless of whose turn it technically is — tap whoever actually got picked, for whichever team actually picked them. Keeps this app's state matching your real draft instead of guessing.

Use league-specific weekly PPR projections instead of the old simulated weekly numbers.

ESPN's internal fantasy API exposes week-level projected stats, but it is unofficial and private leagues require server-side authentication. FantasyPros officially offers weekly NFL projections by API, while SportsDataIO offers continuously refreshed weekly player projections. Keep API keys/cookies on your server — never in this HTML.

ESPN League Sync

Architecture is ready for an ESPN connector, but it is not live yet — this button does not currently connect to a real ESPN league. Public league data can be queried without cookies; private league data requires authenticated session credentials on a secure server. The recommendation engine, trade analyzer and planner in this app are all built against one normalized teams[].roster[] data model and one points/VOR-based scoring engine — a live connector only needs to populate that same shape, and the same "maximize projected points" logic used in the mock draft would immediately apply to your real live picks too.

For a private league, the secure backend should store ESPN authentication server-side. The browser UI never needs to see the credentials.
