# Draft Command Center v24 — Mobile Team Manager

## What changed
- Mobile-first PWA; Chrome extension is optional, not required.
- New **Roster Builder** tab for manually entering/editing all 12 teams.
- Searchable player pool expanded with the 2026 rookie fantasy class and custom-player fallback.
- Add/remove players, rename teams, clear a team, and persist everything locally.
- Existing v23 ESPN bridge remains available on desktop, but the app works without ESPN.

## GitHub Pages
Upload the contents of this folder to the repository root. Open the GitHub Pages URL over HTTPS. On iPhone, use Share → Add to Home Screen.

## Player data note
The built-in pool contains the prior fantasy pool plus the 2026 rookie fantasy class. Because NFL rosters change, the Roster Builder includes **Add Custom** so any player not yet present can be entered immediately without waiting for a new build.
