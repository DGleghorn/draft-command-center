ESPN League Sync

Architecture is ready for an ESPN connector. Public league data can be queried without cookies; private league data requires authenticated session credentials on a secure server. The mock draft engine, trade analyzer and planner in this app are all built against a normalized teams[].roster[] data model — a live connector only needs to populate that same shape.

For a private league, the secure backend should store ESPN authentication server-side. The browser UI never needs to see the credentials.
